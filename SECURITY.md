# Security Policy

## Supported Versions

Since the Open Mathematics Foundation is a client-side, serverless HTML/CSS/JS architecture running entirely inside the client's browser, there are no databases, cloud hosting instances, or remote systems to secure. 

We support security updates for:

| Version | Supported |
| ------- | --------- |
| v1.x    | Yes       |
| < v1.0  | No        |

---

## Reporting a Vulnerability

If you identify a security issue (e.g. potential HTML/XSS injection vulnerabilities in how question prompts, dynamic HTML, or user-input cards render), please follow this process:

1. Do **not** open a public GitHub Issue.
2. Email the maintainer directly at security@openmathfoundation.org.
3. We will acknowledge receipt of your report within 48 hours and work with you to patch the issue on the `main` branch before announcing the vulnerability.
