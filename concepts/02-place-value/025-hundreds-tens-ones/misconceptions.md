# Common Misconceptions: Hundreds, Tens, and Ones

### 1. Zero Placeholder Omission ($405 = 45$)
* **The Trap**: Writing 405 as 45 when hearing *"four hundred five"*.
* **Why it happens**: Forgetting that 0 must hold the Tens place when there are no loose tens.
* **Parent Verbal Prompt**: *"We have 4 Hundreds and 5 Ones, but 0 Tens! Put a 0 in the middle chair."*

---

### 2. Literal Concatenation ($200 + 40 + 3 = 200403$)
* **The Trap**: Writing $200 + 40 + 3 = 200403$.
* **Why it happens**: Appending all numbers side-by-side without overlaying place values.
* **Parent Verbal Prompt**: *"Place values slide on top of each other! 2 hundreds, 4 tens, 3 ones makes 243."*

---

### 3. Confusing Hundreds Flats and Tens Rods
* **The Trap**: Treating a 100-flat as a 10-rod because both represent grouped items.
* **Why it happens**: Visual size misjudgement.
* **Parent Verbal Prompt**: *"A flat is a big square of 100! Count how many 10-rods fit inside it."*
