# Concept Blueprint: Equal Groups

## 1. What the Child Should Understand
- **Structure of Multiplication**: Multiplication is fundamentally about equal groups ($N \text{ groups of } M \text{ items}$).
- **Equal Sizes Matter**: 3 groups with 4 items each is an equal group model ($4 + 4 + 4 = 12$), whereas groups of 3, 4, and 5 are unequal and cannot be multiplied directly.
- **Repeated Addition Link**: $3 \text{ groups of } 4$ is written as $4 + 4 + 4 = 12$ or $3 \times 4 = 12$.

---

## 2. What the Child Should Be Able to Do
- Identify how many groups and how many items per group are shown in a visual set.
- Create equal groups by dragging items into baskets or cups.
- Write or select the matching repeated addition sentence ($3 + 3 + 3 + 3 = 12$) for an equal group model.

---

## 3. Success Criteria & Assessment Rubric
- **Level 1 (Beginning)**: Counts items one by one without noticing that groups have equal numbers of items.
- **Level 2 (Developing)**: Identifies total count but confuses the number of groups with the items per group (e.g., calling 4 groups of 3 "3 groups of 4").
- **Level 3 (Mastered)**: Instantly identifies groups and items per group, calculates total via skip counting or repeated addition, and constructs equal sets effortlessly.
