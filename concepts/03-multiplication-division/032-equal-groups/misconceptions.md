# Common Misconceptions: Equal Groups

## 1. Group / Item Count Confusion
* **The Thinking Trap**: The child swaps the number of groups with the number of items per group (e.g., looking at 4 bowls with 2 cherries each and calling it "2 groups of 4").
* **Why it Happens**: Both numbers represent quantities, so children often list them in whatever order comes to mind first.
* **Parent Verbal Correction Prompt**:
  > *"Point to the containers first — how many bowls are there? That's our number of groups! Now look inside ONE bowl — how many cherries are inside?"*

---

## 2. Counting Items 1-by-1 (Additive Fallback)
* **The Thinking Trap**: Counting every item individually ($1, 2, 3, 4, 5, 6, 7, 8...$) instead of using group structure ($4, 8, 12...$).
* **Why it Happens**: Relying on familiar counting by ones as a safety net.
* **Parent Verbal Correction Prompt**:
  > *"Each group has 4! Instead of counting one by one, can you skip count by 4s or add $4 + 4 + 4$?"*

---

## 3. Treating Unequal Groups as Multiplicative
* **The Thinking Trap**: Trying to multiply groups that have different amounts (e.g. 3 bowls with 3, 4, and 5 items).
* **Why it Happens**: Assuming any collection of groups can be multiplied.
* **Parent Verbal Correction Prompt**:
  > *"Look closely! Are all bowls equal? Multiplication only works when every single group has the exact same number of items!"*
