# Concept Blueprint: Arrays & Multiplication

## 1. What the Child Should Understand
- **Grid Layout**: An array arranges objects into equal rows (horizontal lines) and equal columns (vertical lines).
- **Multiplication Model**: An array of 3 rows with 5 items in each row represents $3 \times 5 = 15$.
- **Commutative Property**: Rotating an array does not change the total number of objects ($3 \times 5 = 5 \times 3 = 15$).

---

## 2. What the Child Should Be Able to Do
- Count the number of rows and columns in a grid array.
- Determine total items by skip counting rows or columns.
- Match an array visual to its corresponding multiplication expression.

---

## 3. Success Criteria & Assessment Rubric
- **Level 1 (Beginning)**: Counts items one by one across the entire grid without leveraging row/column structure.
- **Level 2 (Developing)**: Identifies rows and columns correctly, but confuses which dimension is rows vs columns.
- **Level 3 (Mastered)**: Instantly states row $\times$ column expressions, calculates total via skip counting or mental recall, and demonstrates that turning an array sideways yields the same total.
